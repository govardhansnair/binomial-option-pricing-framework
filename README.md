# binomial-option-pricing-framework
Python-based binomial option pricing, automated market data integration and independent model verification.

This Github includes three files:

1.Binomial_model_Concept:
This file includes the mathematical and visual understanding of the program and its expectations.

2.Binomial_Project_Model:
This file includes an organized one off implementation of integrating the mathematical concepts into a singular code with outputs of underlying price, option prices, delta, gamma, theta and vega. The inputs are manual and the output depends on the respective input data.

3.Live_Binomial_Model:
This file Auto-refreshes every 60 seconds from data provided in yahoo finance and provides a more realistic output based off market conditions. The output can be verified using the previous two files.

The main purpose of this initial project is to implement the mathematical understanding of the binomial financial model using python to get a more immersive and visual comprehension on the concecpt.
In further projects aim to make financial models based off other existing financial models and understand the limitations and expectancies of the effectiveness of understanding the market using the models.
